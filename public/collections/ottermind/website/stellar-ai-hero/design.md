## 布局

**Navigation held to one row** — Navigation is a single row with no second level under it. The bar sits over the 800x708 composition without a background of its own, so the media runs edge to edge underneath it.

**A client row instead of a claim** — Logos sit on the baseline in a single Inter row, unlabelled, which keeps the claim implicit and the composition intact. There is no heading and no border, so the row stays part of the first screen.

**Proof above the fold** — A compact stats strip carries the claims that would otherwise need a paragraph, which keeps the hero section from turning into a feature list. There are no dividers inside the row; spacing alone separates the figures.

**Navigation without a background** — The wordmark holds the left edge and the links run to the right of it, all of it set in Inter so the bar belongs to the page below rather than to a separate system. The bar is a handful of elements, so it rebuilds without a component library.


## 动效

**One duration for the controls** — The controls resolve in 0.1s, fast enough that the page answers as it is touched rather than after it. Easing is specified alongside the duration (0.1s), so a rebuild cannot quietly substitute a different feel.

**Interaction kept local** — Only the controls respond to the pointer (hover states on the buttons and links rather than on every card and tabs or an accordion that swaps content in place), so the page feels responsive without turning every element into a target. Hover and focus are specified together, so the pointer and the keyboard get the same information. Keep the interactive layer small.
