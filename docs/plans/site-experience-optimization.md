# 全站体验优化实施计划

2026-10-30。范围：自有站点 UI；保留第三方媒体、项目主题、首页无限流与独立接入页。不重做已确认的 Hero，不扩充 66 项组件适配器，不自动发布。

## 目标与实施顺序

| 阶段 | 覆盖 | 验收 |
| --- | --- | --- |
| 1 共享基础 | 下拉、搜索、折叠、按钮、焦点、字段、弹层 | 44px 控件、400 字重、0.5px 边框；展开内容无裁切；键盘可操作 |
| 2 资源浏览 | 首页、设计系统、Design.md、组件库列表与详情 | 同一搜索/分类布局，长标签不挤压计数，手机不溢出，空态可恢复 |
| 3 工作流程 | 工作室、项目设计系统、接入详情 | 字段8px间距、组间20–24px；预览与配置分层；提示词完整；下载加载错误可重试 |
| 4 回归交付 | 页面与交互矩阵 | 桌面/768/390px，浅深色，中英文，类型/构建/核心测试；明确未覆盖项 |

## 已确认根因

- 官方组件、兼容包装和旧页面 CSS 并存，部分规则互相覆盖；以共享适配层为入口，避免再在每个页面追加同一修复。
- Accordion 内部固定内容高度，以及默认标题 margin，可能引入空白或裁切；接入页曾局部修补，应统一基础实现。
- 资源工具栏布局分散在两个样式文件，分类不换行且长标签没有压缩边界；统一归入 resource-controls。
- 规范文件加载失败只有下载出口，没有就地重试；补齐恢复路径及空文件保护。
- 下拉菜单已经补齐6px内边距、4px选项间隔，纳入后续回归。

## 交付边界

本轮完成基础一致性与已发现的流程缺陷，建立可复用验收记录。后续新增信息架构或大幅视觉方向另行提出，不能把本轮通过等同于所有第三方组件、所有资源内容均已验证。

## 本轮实施记录

- 共享 Accordion：去除浏览器标题默认外边距，内容自然高度，长标题可换行，边框统一0.5px，内容链接无下划线。
- 共享 Select：保留已完成的菜单留白，补齐16px不可收缩箭头与长标签压缩边界。
- 搜索/分类：将布局归到 resource-controls 单一入口，分类允许换行；390px计数独立一行，不争抢筛选空间。
- Design.md：空结果增加清除筛选，恢复全部内容；与另外两类目录一致。
- 文件资料：增加原位重试与空文件集合保护。
- Review Harness：在核心仓库 creative-os 的统一 rubric 0.3.0 中加入用户十九类复核要求，诊断及独立QA共用。官网继续保留已批准的玻璃页头例外。
