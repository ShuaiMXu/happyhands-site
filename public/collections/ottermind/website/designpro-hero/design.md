## 概述

DesignPro Academy shows one way to build the hero section for an education or community brand, and publishes the instructions that produced it. Colour is limited to black #000000 underneath, white #FFFFFF for the type and teal #64CEFB carrying the accents, set in Inter. If you are briefing a education hero section, start from this composition and replace the subject.

## 布局

**Links collapse at one width** — The bar is the quietest part of the composition: wordmark, a short row of links and one #64CEFB action, all held at the smallest type step in the brief. The links are set below the wordmark in size, and the #64CEFB action is the only element in the bar with any weight.

**The type carries the tone** — The size steps and tracking in the brief are what give this its tone: Inter at a tight display size, then a clear drop to the supporting copy. The display face is used at one size only, so it never competes with itself. Do not add a size without a job.

**Navigation without a background** — The bar sits over the 800x569 composition without a background of its own, so the media runs edge to edge underneath it.

**The scale is the styling** — Numerals share the interface face, so statistics and labels belong to the same system.


## 动效

**The controls are the interactive layer** — Feedback is limited to hover states on the buttons and links rather than on every card, so the rest of the layout is a fixed composition. Each state changes one property, which keeps the feedback legible.

**Motion that stays out of the way** — There is no scroll library here: the 800x569 composition holds still and only the elements that respond to you move. There is no animation library in the brief, which keeps the rebuild small.

## 文案规则

**Why the education brief holds** — Most education pages fail by adding: more sections, more gradients, more claims. DesignPro Academy goes the other way. The composition stays on black #000000 with teal #64CEFB for actions, which is enough to look deliberate. DesignPro Academy states the offer once and lets the composition repeat it rather than adding a second claim.

**How DesignPro Academy sequences the first read** — One screen, one action, and navigation, the announcement badge and the background clip between them. The brief fixes that order rather than leaving the first screen to a stack of sections. A education reader gets the offer before the options.

**The numbers behind the hero section** — Almost every decision here is a value you can check: a 800x569 frame. The media is a still at 800x569. The type stays in Inter, so a substitution has to keep the same proportions. Nothing in this hero section depends on a default.
