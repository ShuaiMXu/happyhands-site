# Guides

> Guides to building UI with a coding agent and a design system, each with an install line or a rule pair from a shipped design.how system.

- [An anti AI slop UI skill, and the checks its lint runs](https://design.how/guides/anti-ai-slop-ui-skill-checks-its-lint-runs.md) (2026-10-25): An anti AI slop UI skill tells an agent which UI habits to avoid, and Quartz lint fails the code. A 15-check review list with rule ids, status dots first.
- [How to make Claude Code UI look better in five steps](https://design.how/guides/how-to-make-claude-code-ui-look-better-in-five-steps.md) (2026-10-25): Make Claude Code UI look better in five steps with Quartz, its skill and a lint whose 35 rules fail on tracked capitals and side rails.
- [How to name Tailwind 4 semantic tokens by their job](https://design.how/guides/name-tailwind-4-semantic-tokens-by-their-job.md) (2026-10-25): Name Tailwind 4 semantic tokens by job, such as text-2 or accent-wash, so a lint can check placement. Quartz's lint fails bg-accent-field on a section.
- [What an agent-ready design system does to your CSS](https://design.how/guides/what-an-agent-ready-design-system-does-to-your-css.md) (2026-10-25): An agent-ready design system gives an agent tokens, components and rules to install, read and check against, and its CSS must leave your Tailwind working.
- [What makes design system rules for AI checkable](https://design.how/guides/what-makes-design-system-rules-for-ai-checkable.md) (2026-10-24): Design system rules for AI carry an id, a level and code that breaks them. How Quartz's anti-slop-no-arrow-links rule maps to its lint error.
- [A shadcn theme for an AI chat app, with the install lines](https://design.how/guides/shadcn-theme-for-ai-chat-app-install-lines.md) (2026-10-21): Three shadcn themes for an AI chat app compared, Quartz, Glaze and Lime, by the tool calls and streaming parts each ships, with the install line for each.
- [Give Cursor a design system in one project rules file](https://design.how/guides/give-cursor-a-design-system-in-one-project-rules-file.md) (2026-10-20): Give Cursor a design system with one .cursor/rules/quartz.mdc file that points it at the Quartz skill, then let Quartz lint's 35 rules catch the rest.
- [How to lint hardcoded colors in Tailwind with Quartz](https://design.how/guides/lint-hardcoded-colors-in-tailwind-with-quartz.md) (2026-10-20): Lint hardcoded Tailwind colors like text-[#18181b] and text-gray-500 with Quartz, and catch the next mistake, a real token such as bg-ink in the wrong place.
- [Approval UI for AI agents that people read](https://design.how/guides/approval-ui-for-ai-agents.md) (2026-10-19): An approval UI for an AI agent asks inside the turn, says what the call will do and ends a refusal as denied. The rules and block Quartz ships for it.
- [How to design a tool call UI people can scan](https://design.how/guides/tool-call-ui-rules.md) (2026-10-19): Tool call UI rules from Quartz, each with the code an agent gets wrong: a seq on every event, explicit status, and a denied call that is not an error.
