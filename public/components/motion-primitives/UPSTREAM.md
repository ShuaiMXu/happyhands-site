# Motion Primitives

Motion Primitives is a community registry for React, Tailwind CSS and Motion. This collection contains four pinned upstream Registry items, with examples rendered from their original component source.

- Source: https://github.com/ibelick/motion-primitives/tree/120f64f6ca60348e251f929e9c81f11ccbe45eda
- License: MIT
- Installation: use the shadcn CLI in a React project with shadcn initialized. Review the dependencies and install only the component you need.
