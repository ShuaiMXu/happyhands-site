# Beautiful UI

Beautiful UI 是面向 AI 应用的 React 组件库。用任务列表追踪进度，用审批卡展示待决定的操作，也可以用代码块、记录表和差异表呈现结果。

## 接入

组件通过 shadcn registry 分发，使用 React 和 Tailwind CSS v4。上游 Sidebar Nav 默认使用商业图标。安装前检查对应 registry 条目，也可以在自己的应用里换成现有图标。

## 视觉基础

上游提供浅色和深色 tokens、Inter 与 JetBrains Mono 字体配置，以及 6px 标签、8px 控件、10px 卡片和 14px 窗口圆角。查看 [Token 文件](registry/foundation.json) 和 [原始组件](https://github.com/slev12397/beautiful-ui/tree/44a274e598395ab61e7c96c26fda2758780253b7/components/primitives)。
