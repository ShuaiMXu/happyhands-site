**A loop, not a timeline** — Ambient movement comes from the 9.4s 988x720 loop rather than from scroll effects, which keeps the page calm and the type readable. The loop is cropped to cover, which means the composition does not depend on a particular frame size.

**One element arrives** — A typewriter pass is the only entrance on the page, so there is one motion idea to maintain. Timing is derived from one value, so a longer line takes longer without being hand-tuned. Do not add a second entrance.
