## 概述

Kresna Footer is a working reference for an AI or SaaS product: the footer laid out, measured and ready to rebuild. The palette runs white #FFFFFF underneath and deep blue #111827 for the type, and the type is DM Sans. It ships as one self-contained HTML file, so the whole footer can be lifted into a project without a design handoff. The brief spends its motion budget on 0.2s transitions. Borrow the structure and not the subject: the footer and its numbers move to your brand unchanged.

## 视觉要点

- Transitions are specified at 0.2s, short enough that the page never feels like it is waiting for an animation.
- The timing budget is state feedback rather than page choreography (0.2s), so a slower rebuild reads as a different design.
- The navigation collapses at max-width 560px and max-width 860px, so the bar has a designed narrow state.

## 布局

**Links collapse at one width** — A short run of links and a single action sit over the footer, held at 28px spacing steps and 0.2s transitions so the bar never competes with the composition behind it. Below 560px the links collapse instead of wrapping onto a second line.

**Figures as typography** — The row is placed high in the footer as proof rather than as decoration. The row is aligned to the same margin as the headline above it.

**One family, two roles** — The type is DM Sans at the top of the scale, with the supporting copy dropped well below it so the hierarchy needs no colour to read. Line height follows the size steps rather than a single global value.

**Panels, not paragraphs** — Where a run of copy would go, this page puts a set of panels, which is what keeps the footer scannable. The grid collapses to one column without changing the panel order.


## 动效

**The surface has grain** — A grain overlay sits on white #FFFFFF, which stops large flat areas from reading as plain colour without adding a gradient. It replaces the gradient a page like this would normally use for depth.

**Fast enough to feel deliberate** — The timings are short and consistent (0.2s), so hover and press states read as one system instead of a set of separate effects. Easing is specified alongside the duration (0.2s), so a rebuild cannot quietly substitute a different feel.


## 可替换项

- Keep DM Sans or pick a face with the same proportions; the size scale is set for those widths, not for a substitute.
- Draft the new copy to the 800x586 frame, then check that the entrance still lands on the same number of lines.
- Retime the entrance to your own 0.2s, but keep a standard ease-out as the curve, because the easing is what reads as this design.
- Write the replacement headline first, then confirm it still fits the 800x586 frame at the reference's type size.

## 文案规则

**Why the SaaS brief holds** — A stock hero and this footer use the same parts. Here they are ordered by navigation, the headline, the announcement badge, the stats row and the card grid and measured with 28px spacing steps, 0.2s transitions and a 560px breakpoint, so the screen reads as a sequence rather than a container. Kresna Footer states the offer once and lets the composition repeat it rather than adding a second claim.

**How the footer reflows** — Most responsive work stops at hiding elements. Here the layout changes shape: the layout shifts at 560px, and nothing important is dropped to make the fold fit. A squeeze would have been cheaper and would not hold.

**The numbers behind the footer** — Almost every decision here is a value you can check: 28px spacing steps, 0.2s transitions and a 560px breakpoint. The media is a still at 800x586. The type stays in DM Sans, so a substitution has to keep the same proportions. Nothing in this footer depends on a default.
