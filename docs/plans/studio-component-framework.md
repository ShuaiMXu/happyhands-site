# 主题工作室组件框架实施计划

2026-10-30。用户已确认全量建立台账；以下为实施顺序，尚未实现的组件不得标记完成。

## 目标与范围

66 项官方目录条目全量纳入覆盖台账，统一框架支持逐项接入。台账不等于完成组件实现。AI 扩展单独管理。

## 1. 全量台账与组件契约

建立 66 项稳定 ID、分类、来源及版本、依赖、配置项、变体、状态、预览入口和导出入口。分别记录可预览、可交互、可换肤、可配置、可导出及验证证据。未接入项明确显示未支持，不以占位演示冒充实现。

验收：目录完整、无重复；所有条目可追踪；首批边界明确。

## 2. 统一组件框架

建立注册表、主题适配、配置面板、预览容器、场景组合与代码导出接口。先审查现有 Base UI/Radix 依赖，确定主底座及例外，避免同类组件重复引入。工作室外壳与项目主题隔离。

验收：按钮、输入框、卡片以同一配置驱动交互预览及导出，不依赖截图模拟。

## 3. Design.md 导入

资源卡片与详情增加以此创建入口。优先读取配套结构化数据，保留原文、来源、字段映射和补全记录；纯 Markdown 经解析与校验。扩展项目数据并迁移旧草稿，保留撤销、保存与恢复能力。缺失字体及深浅色明确标注。

验收：Mercury 与一个浅色参考分别完成导入、调整、保存、重开；来源不被覆盖。

## 4. 工作室呈现与首批组件

左侧提供直观风格设置及组件选择，大区域呈现真实交互；支持组件总览、场景和原始参考。首批接入常用操作、表单、导航、浮层、反馈和内容组件。状态按适用性覆盖默认、焦点、选中、禁用、加载与错误。

验收：桌面与手机、中英文与深浅色；键盘、焦点和长内容；外壳保持无文案下划线。

## 5. 场景、扩展与导出

同一批组件组成登录、设置、邀请、列表、仪表盘及营销内容场景。后续补齐日期、复杂表格、图表、布局与消息类。导出 Design.md、主题变量和受支持的组件代码，保持依赖、配置及来源信息。

验收：导出到独立样例项目运行，对照预览验证；不把静态演示算作业务功能。

## 6. 交付

每批更新覆盖台账及证据，提供可审阅预览。根据仓库规则取得该批预览确认后再合并发布。

## 当前实施批次（2026-10-30）

已建立 66 项目录及能力台账；按钮、输入框和卡片接入同一预览/HTML 导出框架，支持配置、独立撤销与重做。当前三项是原生实现，不冒充完整 shadcn 组件。目录的验证状态仍为 pending，待逐项补齐证据。

Design.md 详情可创建独立主题项目，保留原文、结构化来源及映射记录。已接通结构化颜色、间距与圆角；纯 Markdown 上传、源字体/复杂形态自动还原、卡片快捷入口、完整 React 导出及更多场景尚未完成。

用户最终指定 Radix + Vite + Monorepo + pointer，预设 b1VlItwO。参考工程单独生成，官网沿用现有多入口 Vite 架构，迁入 Luma/Neutral/Inter/Lucide 设计规则。下一批在此接口下接入实际 Radix 组件及状态；不把台账数量当作已实现数量。
