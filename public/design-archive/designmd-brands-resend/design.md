# Resend Design

> Resend is the email API for developers. The brand is minimal, monochromatic, and developer-focused.

## Overview

Resend provides email infrastructure for developers. The design emphasizes simplicity, clarity, and technical precision.

## Design Philosophy

- **Minimal**: Strip away decoration
- **Dark-first**: Primary experience is dark mode
- **Developer-centric**: Clear, direct communication
- **Monochromatic**: Black/white with minimal accents

## Do's and Don'ts

### Do's
- Keep interfaces minimal
- Use black/white as primary
- Maintain high contrast

### Don'ts
- Don't add unnecessary color
- Don't use decorative elements
